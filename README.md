# Ordo Hereticus Archive

Публичный архив материалов для настольных ролевых игр во вселенной Warhammer 40,000, стилизованный под архив Инквизиции Ордо Еретикус.

## Структура архива

- `Audio/` — вокс-записи, литании, фоновые звуки и аудиоматериалы.
- `Video/` — видеозаписи, брифинги и визуальные материалы.
- `Documents/` — досье, отчёты, приказы, протоколы и раздаточные материалы.
- `Heretics List/` — списки подозреваемых, еретиков, культов и связанных дел.
- `DON'T OPEN/` — материалы с ограниченным доступом и сюжетные секреты.
- `Settings/` — шаблоны настроек приложения, синхронизации, интерфейса и контроля доступа.

## Использование

Репозиторий предназначен для синхронизации с приложением **Ordo Hereticus Archive**. Клиентское приложение сможет проверять ветку `main`, загружать новые и изменённые материалы, а также удалять или перемещать в карантин файлы, отсутствующие в репозитории.

## Безопасность

Не добавляйте в репозиторий пароли, токены GitHub, административные литании, секретные ключи, персональные данные и иные реальные конфиденциальные сведения. Папка `DON'T OPEN/` является сюжетным разделом, а не средством настоящей защиты информации.

## Правовой статус

Неофициальный некоммерческий фанатский проект для НРИ. Репозиторий не связан с Games Workshop и не является официальным продуктом Warhammer 40,000.
